# راهنمای ساخت APK با گوشی اندرویدی

این پروژه رابط کاربری React + Vite است. برای ساخت APK نیازی به نصب Android Studio روی گوشی نیست؛ ساخت در GitHub Actions انجام می‌شود.

## مراحل

1. فایل ZIP پروژه را از حالت فشرده خارج کنید.
2. در مرورگر گوشی وارد https://github.com شوید و یک حساب بسازید یا وارد حساب خود شوید.
3. یک مخزن جدید (New repository) بسازید. برای ساده‌تر بودن، می‌توانید آن را Private انتخاب کنید.
4. فایل‌های داخل پوشه پروژه را در ریشه مخزن بارگذاری کنید. حتماً پوشه `.github/workflows` و فایل `build-apk.yml` هم بارگذاری شوند. اگر رابط بارگذاری وب پوشه‌ها را دشوار می‌کند، فایل ZIP را در گوشی استخراج و از بخش Upload files همه فایل‌ها را انتخاب کنید؛ فایل‌های داخل پوشه مخفی `.github` نیز باید اضافه شوند.
5. در مخزن، زبانه Actions را باز کنید و گردش‌کار `Build Android APK` را انتخاب کنید.
6. روی `Run workflow` و سپس دکمه سبز `Run workflow` بزنید.
7. پس از پایان موفق اجرا، وارد اجرای انجام‌شده شوید، بخش Artifacts را پیدا کنید و `load-management-debug-apk` را دانلود کنید.
8. ZIP دانلودشده را در گوشی استخراج کنید. فایل `app-debug.apk` را باز کنید و در صورت درخواست اندروید، اجازه نصب از آن منبع را فعال کنید.

## نکات مهم

- این APK نسخه آزمایشی (debug) است و برای انتشار در فروشگاه بهتر است نسخه امضاشده release ساخته شود.
- اطلاعات برنامه فعلاً در حافظه محلی اپلیکیشن ذخیره می‌شود؛ حذف داده‌های برنامه یا حذف نصب می‌تواند اطلاعات را پاک کند. از قابلیت خروجی/پشتیبان‌گیری برنامه استفاده کنید.
- هیچ رمز، کلید API یا اطلاعات محرمانه‌ای را در مخزن عمومی قرار ندهید.
- اگر Build شکست خورد، وارد اجرای ناموفق Actions شوید و متن خطای قرمز را کپی کنید تا بتوان مشکل را برطرف کرد.
